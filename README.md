# Проект интернет магазин

## Описание
Проект интернет магазина, в котором реализован функционал представления товаров с описанием и количеством

## Функциональность
1. выделены две категории товаров: смартфоны и газонная трава
2. функционал сложения позволяет складывать товары только из одинаковых классов
3. метод добавления продуктов в список защищен от добавления в него различных объектов, 
кроме продуктов определенной категории
